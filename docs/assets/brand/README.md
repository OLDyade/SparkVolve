# Brand mark

The interwoven blue and teal ribbons represent the harness evolving through composition. The violet spark represents the model capability at its center.

`logo.png` is a square PNG with a transparent background, adapted from the project owner's supplied artwork using the built-in image generation tool. The English and Chinese repository homepages use the same asset.

Use the complete mark with its transparent padding. Preserve its proportions and colors. Keep it separate from text so the project name and slogan remain accessible and translatable. The existing sketchnote diagrams retain their own explanatory visual style.

Generation prompts are recorded in `prompts.json`.
