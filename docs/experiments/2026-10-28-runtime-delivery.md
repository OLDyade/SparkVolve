## 已修复的共性缺陷

- **原生沙箱与 HOME 不一致。** Docker 可写的 `/home/node` 不在 DSH workspace-write 的写权限范围。运行时将 HOME/XDG 放入 `/tmp/evolution-home` 的独立 128MiB tmpfs，0700 权限；初始化配置、缓存、数据、状态和运行目录。原生 bash 内直接启动 LibreOffice、按默认用户配置重算得到 `7,42`，不绕开 DSH 沙箱。
- **模型 600 秒之下还有传输 300 秒。** 用原生 Cordis 插件装配匹配的 Undici fetch 与 Agent，将 connect/headers/body 时限对齐运行合同；卸载时释放自有连接池与全局实现。实际 DSH → Pi → OpenAI SDK → HTTP 等待响应头 305 秒后成功，只有 1 次调用，无重试。模型独立截止与取消仍有效。见[实现依据](../research/2026-10-28-runtime-budget-and-home.md)。
- **调用证据不能靠日志猜测关联。** 原生事件保留 session、agent、initiator、执行 token、工具实参／结果和耗时。请求逐个 UUID 开始与终止，usage 只计一次；覆盖工具成功、失败与插件卸载。事件观察不宣称覆盖任意内部服务调用。
- **安装通过还需真实使用。** 新 `verify-installed-capability.mjs` 按明确登记的镜像运行四类任务，核实原生加载器解析路径、Profile patch、源码／构建／归档身份和运行前后完整性；执行不挂载 `/candidate`，独立评分禁网。

## 候选算法不能用高分背书

对原 H2 进行独立、只读的六例通用反例检查，与 LibreOffice 比较，全部发现不一致：`ROUND(2.5,0)`、除零、错误传播、跨表引用、IF 惰性分支和百分数字面量。结果见[原始反例](../evidence/runtime-delivery-20261028/formula-counterexamples.json)。候选实现自建公式解释器，未满足这些语义；未手写修补候选，也未更改原评分。

因此，原始归档保留供复现，**不推荐为验收合格的能力 Bundle**。安装机制通过、任务分数与公式语义通过是独立事实。
