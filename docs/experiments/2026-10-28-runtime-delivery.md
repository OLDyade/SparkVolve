## Common defects that have been fixed

- **Native sandbox and HOME inconsistency.** Docker's writable `/home/node` is not within the write permission scope of DSH workspace-write. The runtime places HOME/XDG in a separate 128MiB tmpfs at `/tmp/evolution-home`, with 0700 permissions; it initializes the config, cache, data, state, and run directories. LibreOffice is started directly inside native bash and recomputed with the default user configuration to obtain `7,42`, without bypassing the DSH sandbox.
- **Below the 600-second model limit there is also a 300-second transport limit.** A native Cordis plugin assembles a matching Undici fetch and Agent, aligning the connect/headers/body timeouts with the run contract; on unload it releases its own connection pool and the global implementation. In practice DSH → Pi → OpenAI SDK → HTTP succeeded after waiting 305 seconds for response headers, with only 1 call and no retry. The model's independent deadline and cancellation remain effective. See [implementation basis](../research/2026-10-28-runtime-budget-and-home.md).
- **Call evidence cannot rely on guessing associations from logs.** Native events retain session, agent, initiator, execution token, tool arguments/results, and duration. Requests start and end individually by UUID, and usage is counted only once; this covers tool success, failure, and plugin unload. Event observation does not claim to cover arbitrary internal service calls.
- **Passing installation also requires real use.** The new `verify-installed-capability.mjs` runs the four task types against explicitly registered images, verifying the native loader resolution path, Profile patch, source/build/archive identity, and integrity before and after the run; execution does not mount `/candidate`, and independent scoring has networking disabled.

## The candidate algorithm cannot be endorsed by high scores

An independent, read-only six-case general counterexample check was performed on the original H2, compared with LibreOffice, and all were found inconsistent: `ROUND(2.5,0)`, division by zero, error propagation, cross-sheet references, IF lazy branches, and percentage literals. Results are in [original counterexamples](../evidence/runtime-delivery-20261028/formula-counterexamples.json). The candidate implementation builds its own formula interpreter and does not satisfy these semantics; the candidate was not hand-patched, and the original scores were not changed.

Therefore, the original archive is retained for reproduction, and is **not recommended as an acceptance-qualified capability Bundle**. Passing the installation mechanism, task scores, and formula semantics are independent facts.
