# Native Startup and Mutation Method Comparison: Design Rationale

Verification date: 2026-10-29. Retain the project's core idea: plugins are the objects of evolution, evolutionary capability is assembled through native DSH plugins, and effective results are delivered as installable Bundles.

| Source | Adopted design | Implementation in this round |
|---|---|---|
| [DSH](https://github.com/deepseek-ai/deepseek-harness/tree/f3803c96974ad4a94195fb97e5c637e9c2a3afe3) | Native services, systemPrompt, tools, and plugin development capabilities; assembled through the existing runtime foundation | The launcher only orchestrates the existing CLI; all groups share the native prompt slot, and no new Agent Loop is created |
| [GEPA](https://github.com/gepa-ai/gepa/tree/80a62c879ecdeb8741faac72a844dceb1c18691f) and [ICLR 2026 paper](https://arxiv.org/abs/2507.19457) | Obtain feedback from actual execution traces and evaluate changes in the optimization target; prompts are one researchable search space | Keep the same G and feedback, and add a prompt-only control; the GEPA algorithm was not run, so it cannot be claimed to outperform GEPA |
| [AutoSaddler](https://github.com/microsoft/AutoSaddler/tree/e841543ce6cf6bdf690e65134b12a829ec9f66d1) | Scenario adaptation and candidate artifact boundaries, distinguishing runnable demos from method gains | recipe replacement task; the formal comparison freezes G/H0 and the data, with independent validation; results from other projects are not transferred |
| [DeepSeek official Anthropic API](https://api-docs.deepseek.com/guides/anthropic_api) | Official Messages interface and native tool calling | Official DeepSeek by default; models and Providers are paired for access, and credentials are held by a trusted proxy |
| [Docker FROM specification](https://docs.docker.com/reference/dockerfile/#from) | Build references are image name/tag/distribution digest; local content IDs differ syntactically from repository digests | The local image name corresponding to the content is used for domain builds, while actual execution still freezes the content ID |

GitHub check: DSH 264,887 stars, GEPA 7,185 stars, AutoSaddler 245 stars. The counts are signals of community scale on that day; AutoSaddler's engineering design is relevant, but it cannot be described as a high-star project. These numbers are not evidence of the effectiveness of the adopted mechanisms. The runtime version remains fixed at DSH 0.2.1-rc.4 / Cordis 4.0.5, and mainline updates do not directly hot-swap experimental dependencies.

X searches also surfaced a [discussion thread](https://x.com/haginota/status/2114956574896840719) on the stability of self-evolution and continual learning, as well as [public exchanges](https://x.com/sunghopark20124/status/2115462880745423107) with researchers working on harness optimization. The former has very low engagement, and the latter discusses directions but has no experimental conclusions; this round added no algorithms or claimed effects based on them. The keyword GEPA also mixed in results from an environmental organization of the same name, which have been excluded.

The substantive increments in this round are two: **make real runs directly launchable; make plugin-level mutation advantages a question that can be tested by comparison.** A single high score, code that builds, or popular discussion cannot replace the latter. The primary metric remains accuracy-oriented, and no hard promotion gates for speed or retention rate were added without authorization.

The actual [three-group results](../experiments/2026-10-29-mutation-space-results.md) have been completed. The run exposed the problem that `{{…}}` in free text was treated by DSH as a template variable; this was then cross-verified through the official Context7 documentation and the installed version's types and implementation: a segment declaring `interpolate: false` preserves the text verbatim. Subsequent seeds were corrected and a real native rendering test was added; the frozen experiment is not hot-modified or rerun. This correction added no evidence of model gains.
