A successful run starts a research question.

The case above demonstrates an end-to-end engineering loop on synthetic tasks. It does not establish stable improvement, unseen-domain transfer or which individual edit caused the gain.

Known semantic defects

The original candidate's optional save path could erase formulas, and its error detector could mistake text beginning with # for an error. These counterexamples remain public alongside the high scores.

The later three-arm study contains six independent searches, twelve source patches and 124 task scorings. Five searches retained H0. An advantage for unrestricted plugin mutation remains unproven.
